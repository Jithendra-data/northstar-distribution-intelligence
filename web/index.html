PUBLIC PROJECT OVERVIEW

How NorthStar turns distribution records into operating decisions.

Decision owners are finance, inventory planning, procurement, and sales operations. The implemented pipeline validates synthetic source records, normalizes staging CSVs, loads an enforced SQLite dimensional warehouse, computes SQL/Python analytics, reconciles five measures, and publishes only an approved dataset. Real ERP connectors and a hosted SQL Server deployment are not implemented.

Implemented, designed, and planned

Implemented: synthetic generation, validated staging, SQLite dimensional loading, SQL monthly sales, Python operational aggregates, publication gates, reproducible manifests, regression tests, static BI.

Designed: SQL Server DDL and enterprise integration/security contracts.

Planned: real ERP connectivity, SSO, row-level permissions, SCD Type 2, production CDC, and a private warehouse service.

What happens when new data is generated

  1. GenerateCreate a new synthetic distribution scenario.
  2. TransformValidate sources, normalize staging, and load SQLite facts.
  3. CheckBlock mandatory failures; document synthetic exceptions.
  4. PublishApprove the candidate, replace atomically, then deploy.

The public site contains synthetic data only. SQLite is a portable reference implementation, not a multi-user enterprise warehouse. Full rebuilds are deliberate at this scale; incremental CDC and historical master data require additional implementation.
